GateWitness replay dashboard

Every result here is recomputed live by the code that produced the paper. Nothing is precomputed.

x axis: seconds from the start of the attack. Shaded: the attack window. Lighter shading: the 60 s after it, during which an alarm still counts. The grey dashed line is the same test on the clean (unattacked) traffic. If it crosses the threshold inside the window, the episode is also a placebo hit.
Each row prints the value exactly as written in the paper, then recomputes it from results/summary.json, results/channel.json and results/derived.json with the same rounding. The rows are the same ones check_paper.py prints.
